# ✅ To-Do 리스트

과제와 일상을 한곳에서 관리할 수 있는 반응형 To-Do 리스트입니다. 카테고리,
우선순위, 마감일을 설정하고 진행률을 확인할 수 있습니다.

## 소개

이 프로젝트는 학생이 과제와 개인 할 일을 잊지 않고 관리할 수 있도록 만든
브라우저 기반 할 일 관리 앱입니다. 별도의 회원가입이나 서버 없이 사용할 수
있으며, 등록한 데이터는 브라우저의 `localStorage`에 저장됩니다.

### 주요 기능

- 할 일 추가 및 삭제
- 할 일 완료/미완료 상태 변경
- 카테고리별 분류: 전체, 과제, 개인, 기타
- 상태별 필터: 전체, 진행 중, 완료됨
- 우선순위 표시: 높음, 보통, 낮음
- 마감일 표시 및 마감일이 지난 미완료 항목 강조
- 전체 할 일 대비 완료율 표시
- 새로고침 후에도 데이터 유지
- 완료 처리 시 꽃잎 파티클 효과
- 삭제 전 커스텀 확인 팝업 및 절망한 표정의 아이콘
- 빈 입력, 200자 초과 입력에 대한 안내
- HTML 태그를 실행하지 않고 일반 텍스트로 표시

## 어떻게 만들었나요

PRD를 먼저 작성한 뒤, 요구사항을 기준으로 화면 구조와 데이터 흐름을
구현했습니다.

1. [PRD.md](./PRD.md)에 기능, 데이터 구조, 상태, 예외 처리 기준을 정의했습니다.
2. [guide.md](./guide.md)의 실습 흐름에 따라 Bootstrap과 Tailwind 버전을
   비교했습니다.
3. 최종 버전은 Tailwind CSS를 사용해 구현했습니다.
4. Vanilla JavaScript로 상태 관리, 필터링, 렌더링, `localStorage` 저장을
   작성했습니다.
5. 이후 완료 효과와 삭제 확인 팝업을 추가해 사용성을 보완했습니다.

### Bootstrap vs Tailwind

| 비교 항목 | Bootstrap | 최종 Tailwind |
| --- | --- | --- |
| 스타일 작성 방식 | 미리 정의된 컴포넌트와 유틸리티 조합 | HTML 클래스 기반 유틸리티 조합 |
| 화면 구성 | 정해진 컴포넌트 스타일을 활용하기 쉬움 | 간격, 색상, 반응형 레이아웃을 세밀하게 조정하기 쉬움 |
| 최종 선택 | 비교용 버전 | 기존 디자인을 유지하면서 빠르게 세부 조정할 수 있어 선택 |

## 실행 방법

### 브라우저에서 바로 실행

GitHub Pages 배포 주소:
[https://heoyr123.github.io/26-w08-todo/](https://heoyr123.github.io/26-w08-todo/)

### 로컬에서 실행

별도의 패키지 설치나 빌드 과정이 필요하지 않습니다.

1. 저장소를 내려받습니다.
2. 프로젝트 폴더에서 `index.html`을 브라우저로 엽니다.

로컬 서버를 사용하려면 다음처럼 실행할 수 있습니다.

```bash
python3 -m http.server 8000
```

그 다음 브라우저에서 [http://localhost:8000](http://localhost:8000)을 엽니다.

## 사용 방법

1. 할 일, 카테고리, 우선순위, 마감일을 입력합니다.
2. **추가** 버튼을 누르거나 입력 폼에서 Enter를 누릅니다.
3. 체크박스를 선택하면 완료 처리되고 진행률이 갱신됩니다.
4. 카테고리 탭과 상태 필터를 조합해 원하는 항목만 확인합니다.
5. 삭제 버튼을 누른 뒤 팝업에서 **삭제하기**를 선택합니다.

## 저장 데이터

할 일 목록은 브라우저 `localStorage`의 `tuturelist-todos` 키에 JSON 배열로
저장됩니다. 브라우저의 사이트 데이터를 삭제하면 저장된 할 일도 함께
삭제될 수 있습니다.

할 일 데이터는 다음 필드로 구성됩니다.

| 필드 | 설명 |
| --- | --- |
| `id` | 할 일을 식별하는 고유 문자열 |
| `text` | 할 일 내용 |
| `completed` | 완료 여부 |
| `dueDate` | 마감일과 시간 |
| `priority` | `high`, `medium`, `low` 중 하나 |
| `category` | `과제`, `개인`, `기타` 중 하나 |

## 커스터마이징한 부분

PRD의 기본 기능 외에 다음 내용을 추가했습니다.

- 완료 순간에 여러 색상의 꽃잎이 흩날리는 시각적 피드백을 추가했습니다.
- 브라우저 시스템 경고창 대신 앱 디자인에 맞는 삭제 확인 모달을 만들었습니다.
- 삭제 모달에 CSS로 만든 절망한 표정의 아이콘을 추가했습니다.
- 모달 바깥 영역 클릭과 `Escape` 키로 취소할 수 있도록 했습니다.
- 모달을 닫은 뒤 삭제 버튼으로 포커스를 되돌려 키보드 사용성을 높였습니다.
- 사용자의 `prefers-reduced-motion` 설정을 존중해 애니메이션을 줄였습니다.
- 입력값을 `textContent`로 렌더링해 HTML 태그가 실행되지 않도록 했습니다.

## 파일 구조

```text
.
├── index.html  # 화면 구조와 접근성 속성
├── style.css   # 꽃잎 효과, 삭제 아이콘, 모션 설정
├── script.js   # 상태 관리, 렌더링, 이벤트 처리, localStorage
├── PRD.md      # 제품 요구사항 문서
└── guide.md    # 실습 및 구현 과정 안내
```
